# 🛒 ATB & Сільпо PRO: Аналітика, Знижки & Порівняння цін

Комплексний веб-додаток та аналітичний інструмент для одночасного моніторингу цін, акцій та асортименту двох найбільших торговельних мереж України — **«АТБ»** та **«Сільпо»**.

---

## 🌟 Основні можливості

### 1. Три режими перегляду магазинів (Store Selector)
- 🛍️ **Усі разом (АТБ + Сільпо)**: паралельний пошук та чергування карток для миттєвого порівняння цін між мережами.
- 🔴 **Тільки АТБ**: фокус виключно на асортименті, акціях «Економія» та спеціальних цінах з карткою АТБ.
- 🟠 **Тільки Сільпо**: каталог та пошук у вибраному супермаркеті Сільпо з акціями «Цінотижики».

### 2. Розширений центр знижок (Discount Hub)
Стрічка швидких вкладок з динамічними бейджами кількості товарів:
- **Всі товари**
- **🔥 Знижки > 50%**
- **💥 Знижки > 30%**
- **💰 Економія > 30 ₴**
- **⚡ Акції мереж** (Цінотижики & Економія)
- **💳 Спец-картки** (Картка АТБ & Власний Рахунок)
- **🪙 До 30 ₴**
- **🏷️ 30 — 100 ₴**
- **💎 Преміум > 200 ₴**

### 3. 10 алгоритмів точного сортування
- За замовчуванням / Релевантність
- Найдешевші ₴ (від найменшої ціни)
- Найдорожчі ₴ (від найбільшої ціни)
- Максимальна знижка % 🔥
- Мінімальна знижка %
- Максимальна економія ₴ 💰
- Мінімальна економія ₴
- Назва А — Я
- Назва Я — А
- Акції та Картки попереду ⚡

### 4. 3D Flip Card (Переворот картки)
- Натискання на картку товару плавно повертає її в 3D просторі.
- На звороті відображається повна таблиця характеристик: країна-виробник, торгова марка, склад продукту, поживна цінність (білки, жири, вуглеводи, калорійність), спосіб обробки, фасування тощо.
- Кнопка прямого переходу для купівлі на офіційному сайті магазину.

### 5. Режим свайпінгу Badoo / Tinder (🔥)
- Інтерактивна колода карток товарів зі знижками.
- Підтримка перетягування мишею та сенсорних жестів на мобільних пристроях.
- Кнопки ❤️ (переглянути/купити товар) та ✕ (наступна пропозиція).

### 6. 5 дизайнерських тем оформлення
- 🛒 **Класика (Світла)**: корпоративні кольори АТБ (червоний) та Сільпо (помаранчевий).
- 🦾 **Кіберпанк 2077**: неоновий жовтий фон, бірюзовий та неоновий червоний акценти.
- 🌸 **Сакура (Каваї)**: ніжні рожеві тони та округлі форми.
- ⬛ **Бруталізм**: жорсткі чорні рамки, контрастні тіні, шрифт Space Mono.
- 💻 **Термінал (Хакер)**: матричний чорний фон та неоново-зелений моноширинний текст.

### 7. Офіційна інтеграція з Silpo MCP та програмою лояльності
- Авторизація за стандартом OAuth 2.1 PKCE.
- Відображення імені користувача, номера картки «Власний Рахунок» та балансу бонусів у реальному часі.

### 8. Експорт даних
- Завантаження знайдених товарів у форматах **Excel (.xlsx)** зі стилізованими кольоровими рядками під мережу, **CSV** або **JSON**.

## 🚀 Швидкий запуск

### Варіант 1: Подвійний клік на Mac (найпростіше)
Двічі клікніть файл `start.command` у цій папці. Відкриється термінал, запуститься сервер, і додаток автоматично відкриється у вашому веб-браузері:
👉 **http://localhost:5050**

### Варіант 2: Через термінал
```bash
./run.sh
```

або напряму через Python:
```bash
python3 app.py
```

## 📁 Структура проєкту

```
├── app.py               # Головний Flask сервер (паралельний пошук, сортування, експорт, MCP)
├── atb_api.py           # Модуль парсингу магазину «АТБ» (atbmarket.com)
├── silpo_api.py         # Клієнт REST API супермаркету «Сільпо» (sf-ecom-api.silpo.ua)
├── silpo_mcp.py         # Клієнт Silpo AI Factory MCP (OAuth 2.1 PKCE)
├── start.command        # Скрипт запуску в один клік для macOS
├── run.sh               # Bash-скрипт запуску із перевіркою залежностей
├── requirements.txt     # Залежності Python (Flask, requests, beautifulsoup4, openpyxl)
├── templates/
│   └── index.html       # Головний HTML-шаблон (3 режими, вкладки знижок, 3D картки, свайп, MCP)
└── static/
    ├── style.css        # Стилі, 5 тем, анімації 3D карток та свайпінгу
    └── app.js           # Клієнтська логіка фільтрації, сортування, жестів та експорту
```
